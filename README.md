# My Budget Tracker

## Project Description

My Budget Tracker is a simple web application designed to help users track and manage their daily expenses. It allows users to enter expense information and view recorded expenses in a clear and organized table.

This project was developed as part of the HTML and CSS technical coding challenge.

## Features

- Add expense information using a form
- Select an expense category from a dropdown
- Display expenses in a structured table
- Show expense name, amount, category, and date
- Use alternating table row colors
- Highlight table rows when the mouse moves over them
- Include a budget tracker logo
- Include a budgeting tips YouTube video
- Include a collapsible "How to use this tracker" section
- Responsive and clean page layout

## Technologies Used

- HTML5
- CSS3

1. Download or clone the project.

3. Open `index.html` in a web browser.
